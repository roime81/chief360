# Orchestrator 360

Orchestrator 360 is a CEO-facing company operations dashboard: a single “control tower” for reviewing organizational structure, company and division KPIs, workflows, employee lifecycle status, AI-generated division reports, and potential Malaysian regulatory compliance gaps.

The project is currently a **front-end prototype**, not a production-ready operations system. Dashboard figures and records come from local sample data in `src/lib/placeholder-data.ts`; changes are not persisted to a database. The sign-in screen is a visual placeholder: clicking **Sign in with Google** navigates to the dashboard but does not authenticate a user or enforce the displayed super-admin role. AI reports and compliance analysis are implemented as server-side Genkit flows using Google Gemini, and require an API key.

## What’s included

- **Dashboard** (`/dashboard`): sample company metrics, division performance, and recent activity.
- **Org Chart** (`/dashboard/org-chart`): sample reporting structure.
- **KPI Monitoring** (`/dashboard/kpi-monitoring`): company, division, and individual sample KPIs.
- **Workflows** (`/dashboard/workflows`): sample workflow status and progress.
- **Employees** (`/dashboard/employees`): sample employee records and lifecycle statuses.
- **AI Reports** (`/dashboard/reports`): submit division KPIs, trends, challenges, and reporting metrics to generate a report.
- **AI Compliance** (`/dashboard/compliance`): submit company-practice and documentation text for an AI review focused on LHDN, PERKESO, and KWSP.

The AI output is generated by a language model and may be inaccurate or incomplete. It is not legal, tax, or compliance advice; verify findings with qualified professionals and current official guidance. Avoid entering sensitive or personally identifiable information into AI forms.

## Requirements

- Node.js 20 or later
- npm
- A Google AI API key to use the AI Reports and AI Compliance features

## Install and run

```bash
git clone https://github.com/roime81/chief360.git
cd chief360
npm install
```

Create a `.env.local` file in the project root and add your Google AI API key:

```dotenv
GOOGLE_GENAI_API_KEY=your_google_ai_api_key
```

Get an API key from [Google AI Studio](https://aistudio.google.com/apikey). Keep the key private: do not commit it or expose it in client-side code. Environment files are ignored by Git.

Start the development server:

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002). The development script starts Next.js on port `9002`.

## How to use

1. Open the app. The sign-in screen is currently a prototype and does not verify identity.
2. Select **Sign in with Google** to open the dashboard. This navigation is not real Google authentication.
3. Use the sidebar to explore the dashboard, organization chart, KPIs, workflows, employees, AI reports, and AI compliance pages.
4. On **AI Reports**, select a division, enter its KPIs, trends, challenges, and reporting metrics, then choose **Generate Report**. The result appears on the page.
5. On **AI Compliance**, describe company practices and paste relevant documentation excerpts, then choose **Analyze Compliance**. The potential gaps and recommendations appear on the page.

The forms include example values to demonstrate the AI features. Replace them with appropriate, non-sensitive test information. Dashboard pages use sample records and are not connected to the AI form data.

## Technology

- [Next.js](https://nextjs.org/) App Router and React

- Tailwind CSS and Radix UI-based components

## Current limitations

- There is no implemented Google authentication, authorization, or super-admin enforcement.
- Dashboard content is hard-coded sample data; there is no database or persistence layer.
- AI features require a valid Google AI API key and network access to the provider.
- AI compliance checks are informational only and do not replace review against current official regulations.
- The project does not currently include automated tests.

Before using this application with real company data, implement and verify authentication and access control, connect trusted data sources and persistence, and review privacy, security, and regulatory requirements.
