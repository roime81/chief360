# **App Name**: Orchestrator 360

## Core Features:

- Dashboard Overview: Provide a real-time overview of company performance, including active employees, workflows, pending tasks, and completed tasks, mimicking the UI of the provided image.
- Dynamic Org Chart: Dynamically generate and display the company's organizational chart, allowing for real-time updates and visualizations of departmental structures and reporting lines.
- KPI Monitoring: Monitor and display key performance indicators (KPIs) at the company, division, and individual levels.
- Workflow Management: Manage and track workflows across different divisions and departments, ensuring efficient process execution.
- Employee Lifecycle Management: Handle employee onboarding and offboarding processes, tracking employee status and relevant documentation.
- Integrated Reporting: Generate custom reports for each division, providing unique insights and analytics to support decision-making.
- AI-Powered Regulatory Compliance Tool: AI tool to cross-check and validate company practices against regulations from LHDN, PERKESO, KWSP, and similar authorities. It alerts the CEO to potential compliance gaps based on document analysis.
- Google Login with Super Admin: Implement secure Google Login for all users, with roimepuniran@gmail.com designated as the super admin account with full privileges.

## Style Guidelines:

- Primary color: Soft blue (#A0CFEC) to give a professional and calming feel.
- Background color: Very light desaturated blue (#F5F9FC).
- Accent color: Indigo (#4B0082) for key actions and highlights, providing contrast and emphasis.
- Headline font: 'Poppins', sans-serif, for headlines and titles. Its modern, geometric style helps the UI stay fresh.
- Body font: 'PT Sans', sans-serif, for body text and descriptions, where readability is key.
- Use clean, modern icons representing different modules, departments, and actions. Icons should follow a consistent style throughout the application.
- Follow a clean and intuitive layout similar to the provided image, ensuring ease of navigation and a seamless user experience. Use card-based designs to organize information.
- Incorporate subtle animations for transitions and interactions, enhancing the overall user experience and providing visual feedback.
